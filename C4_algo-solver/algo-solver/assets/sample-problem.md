# 示例题目（Sample Problem）—— 两数之和

> 这是 `algo-solver` 技能的演示用例，供 Step 3/4 测试 `judge.py` 时使用。

## 题目描述

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出和为目标值的
**两个**整数，并返回它们的数组下标（从 0 开始）。你可以假设每种输入只会对应一个答案。
但是，数组中同一个元素在答案里不能重复出现。

## 输入格式

第一行一个整数 `n`（2 ≤ n ≤ 10^5），表示数组长度。
第二行 `n` 个整数，为数组元素。
第三行一个整数 `target`。

## 输出格式

输出两个整数，中间用一个空格分隔，表示两个数的下标（先小后大）。

## 示例

输入：
```
4
2 7 11 15
9
```
输出：
```
0 1
```

## 约束

- 2 ≤ n ≤ 10^5
- -10^9 ≤ nums[i] ≤ 10^9
- -10^9 ≤ target ≤ 10^9

## 期望算法

哈希表，`O(n)` 时间、`O(n)` 空间。暴力 `O(n^2)` 在 `n=10^5` 下会 TLE。

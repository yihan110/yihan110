## 三、如何发布（5 分钟 SOP）

```
1. 打开 ruanyihan_C4B_output.html（预览页，带手机外框）
2. 逐屏检查排版：标题 / 目录 / Callout 高亮框 / 表格 / 代码块 / 公式 / 页脚
3. 点击右上角「复制正文」按钮
4. 打开 mp.weixin.qq.com → 登录 → 内容与互动 → 新的创作 → 图文消息
5. 在正文区 Ctrl+V 粘贴
6. 手动补齐：
   - 标题（复制：一个人 + 一个 AI = 一个内容工厂……）
   - 作者：阮依涵
   - 摘要：写公众号最耗时的从来不是「写」，而是排版……
   - 封面图（建议使用技能运行截图）
7. 点击「预览」→ 发送到手机 → 手机上看一遍
8. 确认无误 → 群发 / 发布
```

### 粘贴后需要人工确认的 3 件事

| 项目 | 原因 |
|------|------|
| 封面图 | 必须在公众号后台上传，脚本无法代传 |
| 图片素材 | base64 会在粘贴时自动转存素材库，粘完扫一眼有没有缺图 |
| 原文链接 / 话题标签 | 平台侧设置，不在 HTML 里 |

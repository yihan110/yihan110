# 复杂度速查表（Complexity Cheat-Sheet）

用于 Step 2 算法选择：根据约束规模，判断哪种复杂度可行、选哪个算法。
**原则**：现代 OJ 单点时间限制通常是 1–2 秒，Python 常数约为 C++ 的 5–10 倍。
在 C++ 下，`10^8` 次基础操作约 1 秒。

## 约束 → 可行复杂度对照

| 约束规模 | 可行复杂度 | 典型算法 |
|----------|-----------|----------|
| n ≤ 20 | O(2^n), O(n·2^n), O(n!) | 暴力枚举、位运算状压 DP、回溯、排列 |
| n ≤ 500 | O(n^3) | Floyd-Warshall、矩阵乘法、三重循环 DP |
| n ≤ 10^3 | O(n^2) | 双层循环、最长上升子序列朴素 DP、区间 DP |
| n ≤ 10^4 | O(n^2) 勉强 / O(n√n) | 分块、根号分治 |
| n ≤ 10^5 | O(n log n) | 排序、二分查找、双指针、堆、线段树、树状数组、DSU、KMP |
| n ≤ 10^6 | O(n) | 前缀和、滑动窗口、哈希表、线性筛、单调栈/队列 |
| n ≤ 10^7 | O(n)（常数小） | 简单线性扫描 |
| n ≤ 10^9 | O(log n) 或 O(1) 数学 | 快速幂、矩阵快速幂、数论（整除分块）、公式推导 |
| 大整数 | — | Python 内置大整数，或 C++ 高精度 |

## 常见算法时间复杂度

| 算法 | 时间 | 空间 |
|------|------|------|
| 快速排序 / sort | O(n log n) | O(log n) |
| 归并排序 | O(n log n) | O(n) |
| 二分查找 | O(log n) | O(1) |
| 哈希表查找/插入 | O(1) 平均 | O(n) |
| 平衡树（set/map） | O(log n) | O(n) |
| 二叉堆 push/pop | O(log n) | O(n) |
| 并查集 find/union | O(α(n)) | O(n) |
| 单源最短路 Dijkstra（堆优化） | O((V+E) log V) | O(V+E) |
| Floyd-Warshall | O(V^3) | O(V^2) |
| KMP 字符串匹配 | O(n+m) | O(m) |
| 快速幂 | O(log b) | O(1) |
| 线性筛素数 | O(n) | O(n) |

## 选择算法时的思考顺序

1. **读约束**，确定上界（n 最大多少、T 多少组）。
2. **估算最朴素做法复杂度**，判断是否 TLE；若 TLE，往下降一档。
3. **匹配数据结构**：需要快速查重/查找 → 哈希表；需要区间最值/求和 → 线段树/树状数组/前缀和；
   需要单调性质 → 双指针/单调栈/单调队列；需要分组连通 → 并查集；需要第 k 大 → 堆/对顶堆。
4. **注意乘法溢出**：`n ≤ 10^5` 时 `n*(n-1)/2` 可达 `5×10^9`，必须用 `long long`。
5. **注意多测**：是否读入 `T`，是否读到 EOF，读完后是否要清空全局数组。

## 常见坑（Wrong Answer / TLE / RE 来源）

- 输出格式多一个空格/少一个换行 → WA。
- 忘记 `long long`，`int` 溢出 → WA。
- 数组开小了 1，越界 → RE 或 WA。
- 多测未清空全局/静态数组 → WA。
- 用了递归深度过大（如 `10^5` 层 DFS）→ 栈溢出 RE；改迭代或加 `#pragma comment`/`sys.setrecursionlimit`。
- 浮点数比较用 `==` → 精度问题；用 `fabs(a-b) < eps` 或 `round`。

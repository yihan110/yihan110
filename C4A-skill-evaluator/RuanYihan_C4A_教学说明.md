# RuanYihan — C4A 教学说明：c4-skill-evaluator（技能提交自动评审器）

> 挑战：C4A 技能提交自动评审 ｜ 提交人：RuanYihan（阮依涵） ｜ 版本：v1.2
> 目标：**教会任何老师 / 助教 / 同学 5 分钟上手**——装好就能自动评审一整个群的 C4 提交。

---

## 一、这个东西是干嘛的（30 秒理解）

你给它**一个文件夹路径**（WeChat 群同步目录 / 手动下载目录 / 任意装了 C4 提交的文件夹），
它自动帮你完成 4 件事：

1. **扫描**：找出所有 C4 提交，按作者分组，识别命名不规范者。
2. **查完整性**：每人 5 个必需文件（skill 说明 / 可执行 / demo / 教学说明 / AI 日志）齐不齐。
3. **评质量**：按 C4 四条件（可复用 / 可执行 / 可验证 / IO 明确）打分。
4. **出报告**：Markdown 报告 + Excel 详表 + HTML 仪表板（含排名、改进建议、版本轨迹）。

> 一句话：把老师逐份看群文件的活儿，交给它自动干，你只管看排名和补建议。

## 二、装好就能用（前置条件）

| 组件 | 需要吗 | 怎么检查 |
|------|--------|----------|
| Python 3.10+ | ✅ 必须 | `python --version` |
| openpyxl、pyyaml | ✅ 必须 | 见下方一键安装 |

**一键安装依赖：**
```bash
pip install -r requirements.txt
```
（或 `pip install openpyxl pyyaml`）

> 不需要任何 OJ 账号、不需要联网、不需要 API Key——纯本地离线运行。

## 三、上手 5 步（照着做）

### 第 1 步：拿到技能包
解压/使用 `RuanYihan_C4A_skill-evaluator.skill` 文件夹即可，里面是源码 + 文档 + 测试。

### 第 2 步：装依赖
```bash
cd RuanYihan_C4A_skill-evaluator.skill
pip install -r requirements.txt
```

### 第 3 步：跑评审（关键命令）
```bash
python scripts/run_c4_evaluator.py "C:/你的群文件文件夹路径" --out ./评审结果
```
- 参数 1（必填）：要扫描的文件夹路径。
- `--out`：报告输出目录（默认输出到该文件夹上级）。
- `--rubric`：（可选）自定义评审规则文件。
- `--llm`：（可选）启用 LLM 深度评审层（需自行实现 `LLMReviewer`，默认关闭）。

### 第 4 步：看结果
```
./评审结果/
├── 评审报告.md      ← 完整报告（班级总览 + 作者详情 + 排名 + 建议）→ 直接贴群/发给老师
├── 评审数据.xlsx    ← Excel 详表（按作者一行，含状态与评级）→ 老师可排序筛选
└── 评审仪表板.html  ← 可视化仪表板（双击打开浏览器即看）
```

### 第 5 步：交付
把 `评审报告.md` 发到群里，帮每位同学看到自己的完整性、质量分和改进建议。

## 五、常见坑（我踩过的，帮你避开）

| 坑 | 现象 | 解法 |
|----|------|------|
| 文件夹路径带中文/空格 | 命令报错 | 用英文引号包住整个路径 |
| 没装 openpyxl | 报 `ModuleNotFoundError` | `pip install -r requirements.txt` |
| 群文件里有个人草稿/杂图 | 被当成提交 | 技能会自动过滤"非 C4 文件"，并在报告末尾单列 |
| 同学命名不规范 | 作者被识别成"Unknown" | 技能先按子文件夹名/内容回退；仍 Unknown 的会标记"需人工确认" |
| 有人交了 v1、v2 | 不知道哪个最新 | 技能做版本追踪，排名用最新版并展示迭代轨迹 |
| Windows 下命令找不到 python | 报 9009 | 用 `python` 代替 `python3` |

## 六、进阶：想调评审标准 / 接 LLM

1. **改评审规则（推荐，不用改代码）**：编辑 `references/c4_rubric.yaml`
   （文件名模式、内容信号、正/负向信号、评分权重），改完重新跑即可。
2. **接 LLM 深审**：继承 `src/quality.LLMReviewer` 实现 `review()`，然后
   `run_evaluation(..., llm_reviewer=我的Reviewer())`。
3. **跑单元测试自检**：
   ```bash
   python -m unittest discover -s tests -p "test_*.py" -v
   ```
   16 项测试全绿 = 评审器行为符合预期（含误判率回归）。

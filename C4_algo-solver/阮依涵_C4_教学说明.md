> 目标：**教会别人真正用起来**。本文件 = 上手教程 + 常见坑 + 优化技巧。

---

## 一、这个东西是干嘛的（30 秒理解）

你把一道算法题丢给它，它给你三段东西：
1. `solution.cpp` / `solution.py` —— **直接能提交**的 ACM 模式代码；
2. `problem.md` —— 题目重述 + 约束 + 用的算法 + 复杂度；
3. `verdict_report.txt` —— **它自己跑评测的凭证**，告诉你每个用例过没过。

关键点：**它在把代码给你之前，已经用随附的 `judge.py` 帮你测过了**。所以你不必"写完就盲交，WA 了再改"。

## 二、装好就能用（前置条件）

| 组件 | 需要吗 | 怎么检查 |
|------|--------|----------|
| Python 3 | ✅ 必须（跑 judge.py 和 Python 题解） | `python --version` |
| g++（C++ 编译器） | ⭕ 可选（用 Python 题解就不需要） | `g++ --version` |

> 没有 g++ 完全不影响使用：让技能输出 Python 题解即可，验证照常跑。
> 没有 Python 的话，装一个（官网 python.org 下载，勾选 Add to PATH）。

## 三、上手 5 步（照着做）

### 第 1 步：解压 .skill 包

`.skill` 就是 tar.gz，解压后得到一个 `algo-solver/` 文件夹。用系统自带 tar 或解压软件都行。

### 第 2 步：给技能一道题

在豆包/Claude 里安装这个技能，然后说（任意一种都行）：

```
解这道题：<题目文字>
帮我写这道题的 ACM 代码
算法题：<粘贴题面>
```

也可以直接上传题目截图。

### 第 3 步：看它给的 problem.md

重点核对 **约束** 和 **输出格式** 两行——这是决定算法、导致 WA 的关键。如果它没写约束，你自己补上。

### 第 4 步：让它跑评测（可验证的关键）

它会自动建 `tests/` 并放好样例。你也可以自己加测试：

```
tests/
├── 1.in   1.out      # 官方样例
├── 2.in   2.out      # 你自己想的边界
└── 3.in   3.out
```

然后运行（在技能目录里）：

```bash
python3 scripts/judge.py solution.py --tests ./tests
```

看到 `Summary: N/N PASS` 就是全过。**有 FAIL 就让它改，改到全过再提交。**

### 第 5 步：提交

把 `solution.cpp` / `solution.py` 交到 OJ。输出格式它已经按题面处理好了，直接复制。

## 四、常见坑（我踩过的，帮你避开）

| 坑 | 现象 | 解法 |
|----|------|------|
| **约束没填** | 算法选错，TLE | 一定先确认 `n` 的量级，再看复杂度表 |
| **输出多空格/少换行** | 本地对，交上去 WA | 让技能严格按题面输出格式写；用样例比对 |
| **int 溢出** | 大样例 WA | 涉及和/乘积一律 `long long`（题解里默认做了） |
| **只测样例** | 边界崩 | 一定要加边界用例：`n=1`、最大值、负数、空输入 |
| **没装 g++** | 编译失败 | 改用 Python 题解，或装 MinGW-g++ |
| **多测没清空** | 第二组开始错 | 多组输入要读 `T` 或 `EOF`，并重置全局数组 |
| **Windows 下 `python3` 报 9009** | 命令找不到 | 用 `python` 代替 `python3`（Windows 应用商店占位符的坑） |

## 五、优化技巧（进阶）

1. **边界用例要多而狠**：n=1、n=最大、全相同元素、极限负数、空输出。评测器是免费的，多测不亏。
2. **要讲解，不要只抄代码**：让它把"为什么这个算法 + 复杂度 + 正确性"讲清楚，学得才快。
3. **用 `--tl` 调时限**：`--tl 1` 可以提前发现超时的算法（更快暴露 TLE）。
4. **测试集可复用**：同一套 `tests/` 可以反复测不同写法，方便对比两种解法。
5. **想支持更多语言**：在 `scripts/judge.py` 里加一个编译器分支即可，比对逻辑通用。
6. **命中率最高的话术**：给它"题目 + 约束 + 官方样例"，比只给一句话题面准确得多。

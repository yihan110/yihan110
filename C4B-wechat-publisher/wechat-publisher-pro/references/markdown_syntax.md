# Markdown 语法速查（markdown_syntax.md）

本技能在标准 Markdown 之上增加了 4 类扩展语法：**元数据**、**Callout 高亮框**、
**数学公式** 与 **分隔符**。

## 1. 文章元数据（YAML frontmatter）

写在文件最开头，用 `---` 包裹：

```markdown
---
title: 文章标题          # 会写入预览页标题
subtitle: 副标题         # 可选，居中显示在作者行上方
author: 阮依涵           # 作者，显示在标题下方
date: 2026-10-11        # 日期
digest: 一句话摘要       # 会渲染成虚线摘要框
cover: 封面图说明        # 仅作记录，封面需在公众号后台上传
---
```

命令行 `--author` / `--date` 可覆盖 frontmatter。

## 2. Callout 高亮框

语法：`> [!类型] 可选标题`，后续 `> ` 行是该框的正文。

```markdown
> [!NOTE] 核心结论
> 支持多行正文，也支持 **加粗**、*斜体* 与 `行内代码`。

> [!WARNING] 注意
> 警告内容。

> [!TIP]
> 不写标题时使用该类型的默认标题。
```

### 可用类型与中文别名

| 英文标记 | 中文别名 | 图标 | 默认标题 |
|---------|---------|------|---------|
| `[!NOTE]` | `[!知识]` `[!知识点]` | 📘 | 知识点 |
| `[!TIP]` | `[!提示]` `[!技巧]` | 💡 | 小技巧 |
| `[!IMPORTANT]` | `[!重点]` `[!重要]` | ❗ | 重点 |
| `[!WARNING]` | `[!注意]` `[!警告]` | ⚠️ | 注意 |
| `[!DANGER]` | `[!避坑]` `[!危险]` | 🚫 | 避坑 |
| `[!PRACTICE]` | `[!实践]` `[!动手]` | 🔧 | 动手实践 |
| `[!SUCCESS]` | `[!完成]` `[!成功]` | ✅ | 完成 |
| `[!QUOTE]` | `[!引言]` `[!引用]` | 💬 | 引言 |
| `[!INFO]` | `[!说明]` | ℹ️ | 说明 |
| `[!QUESTION]` | `[!思考]` `[!问题]` | ❓ | 思考 |

也可以用中文书名号写法：`> 【注意】标题`。

> [!IMPORTANT] 为什么标记必须识别在 Markdown 解析**之前**
> 如果先解析再识别，`> [!NOTE] 标题` 与下一行正文会被 Markdown 合并进
> **同一个 `<p>`**，标题和正文粘成一团，无法可靠拆分。本技能在解析前逐行扫描，
> 因此能稳定区分「标记行」与「正文行」。

## 3. 数学公式

```markdown
行内公式：$E = mc^2$
块级公式：

$$\int_0^1 x^2\,dx = \frac{1}{3}$$
```

公式会被渲染成透明底 PNG 并以 base64 内嵌。使用 matplotlib mathtext 语法
（支持常见 LaTeX 记号：`\frac` `\sum` `\int` `\times` `\alpha` 等）。

> [!TIP] 公式很占体积
> 每张公式图约 2–6 KB。长文里公式过多会显著增大粘贴体积，建议只对关键公式
> 使用图片渲染，其余用纯文本表达。

## 4. 分隔符

```markdown
---
```

渲染为居中圆点分隔符 `· · ·`（因为 `<hr>` 不在公众号白名单，会被静默丢弃）。

## 5. 标准语法支持情况

| 语法 | 支持 | 渲染结果 |
|------|------|---------|
| `## 标题` / `### 小标题` | ✅ | `<h2>` / `<h3>`（带主题样式） |
| `# 标题` | ✅ | 自动降级为 `<h2>` |
| `#### 及更深` | ✅ | 统一下沉为 `<h3>` |
| `**加粗**` / `*斜体*` | ✅ | `<span style="font-weight:bold">` / `italic` |
| `` `行内代码` `` | ✅ | 带底色的 `<span>` |
| ` ```语言 ` 代码块 | ✅ | 圆角 `<p>` + 语言标签 + `<br>` 换行 |
| `- / 1.` 列表 | ✅ | `<ul>` / `<ol>`，带缩进与符号 |
| 表格 | ✅ | 全宽表格，表头带主题底色 |
| `> 引用` | ✅ | 左侧竖线引用块 |
| 链接 `[文字](url)` | ✅ | 带下划线的主题色链接 |
| 图片 `![alt](path)` | ✅ | 本地图片自动转 base64；外链保留并告警 |
| 脚注 `[^1]` | ⚠️ | Markdown 正常解析，但公众号内的锚点跳转可能失效 |
| 任务列表 `- [ ]` | ❌ | 未启用，请改用 `- ` 列表 |
